Study MBBS Abroad - Responsive Landing Page 🌍🩺

This project is a responsive landing page designed for students interested in studying MBBS abroad. It includes country listings, admission details, and a lead generation form with real-time validation and tracking.

🚀 Features

✅ Fully Responsive – Works on all screen sizes
✅ SEO Optimized – Improves search engine ranking
✅ Fast Loading – Optimized for speed and performance
✅ Lead Generation Form – Captures user details
✅ Country-Specific Phone Code – Auto-selects based on country
✅ Form Validation – Ensures correct inputs
✅ Success Popup – Confirms form submission
✅ Google Analytics & Facebook Pixel – Tracks user interactions

📁 Folder Structure

📂 project-folder/
│── 📄 index.html         # Main HTML file
│── 📄 styles.css         # Stylesheet (CSS)
│── 📄 script.js          # Handles country phone code selection
│── 📄 validation.js      # Form validation script
│── 📄 README.md          # Project Documentation

 1.	Google Analytics:
	•	Go to Google Analytics and create an account.
	•	Copy the tracking code and paste it inside <head> in index.html.
	
 2.	Facebook Pixel:
	•	Go to Facebook Pixel and generate a Pixel ID.
	•	Add the provided script in <head> of index.html.
